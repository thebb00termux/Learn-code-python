💬 Chat cộng đồng

Dùng biệt danh, không đăng mật khẩu, số điện thoại, địa chỉ hoặc thông tin riêng tư. Chat yêu cầu Firebase Authentication ẩn danh và Realtime Database.

● Chưa kết nối Firebase. Cần điền cấu hình Firebase bên dưới.
Tin nhắn sẽ xuất hiện ở đây khi Firebase được cấu hình.
⚙️ Cấu hình Firebase

Tạo ứng dụng Web trong Firebase Project settings, bật Authentication → Sign-in method → Anonymous, tạo Realtime Database rồi điền các giá trị firebaseConfig. Không dán private key hoặc service account vào HTML.

Cấu hình Firebase Web không phải mật khẩu quản trị. Quyền truy cập phải được bảo vệ bằng Realtime Database Rules bên dưới.

🛡️ Realtime Database Rules

Dán rules này vào Realtime Database → Rules. Nó cho phép người đã đăng nhập (kể cả tài khoản ẩn danh) đọc chat và chỉ tạo tin nhắn mới mang UID của chính họ; không cho sửa/xóa tin đã gửi.

{
  "rules": {
    ".read": false,
    ".write": false,
    "chats": {
      ".read": "auth != null",
      ".indexOn": ["createdAt"],
      "$messageId": {
        ".write": "auth != null && !data.exists() && newData.child('uid').val() == auth.uid",
        ".validate": "newData.hasChildren(['uid', 'name', 'text', 'createdAt'])",
        "uid": {
          ".validate": "newData.isString() && newData.val() == auth.uid"
        },
        "name": {
          ".validate": "newData.isString() && newData.val().length > 0 && newData.val().length <= 24"
        },
        "text": {
          ".validate": "newData.isString() && newData.val().length > 0 && newData.val().length <= 500"
        },
        "createdAt": {
          ".validate": "newData.isNumber() && newData.val() <= now && newData.val() >= now - 60000"
        },
        "$other": {
          ".validate": false
        }
      }
    }
  }
}

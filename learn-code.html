💬 Chat

  

  

   
Chat nhiều người cần một máy chủ. Bạn dùng Firebase (miễn phí):

   
    
    
  1. Tạo project tại console.firebase.google.com
    2. 
    
  2. Build → Authentication → bật Email/Password. Rồi Settings → Authorized domains → thêm tên miền GitHub Pages của bạn (ví dụ thebb00termux.github.io).
    3. 
    
  3. Build → Firestore Database → Create database.
    4. 
    
  4. Firestore → tab Rules → dán Rules bên dưới → Publish.
    5. 
    
  5. Project settings → Your apps → Web → chép firebaseConfig vào biến FIREBASE_CONFIG ở đầu phần <script> trong file này, rồi upload lại.
    6. 
   

   
   
   

   
Chế độ thử chỉ lưu tin nhắn trên máy bạn, chưa chat được với người khác.
